# Governance (Class A pack)

Short rules for this public repository.

## What this repo is

**Release Class A** — curated Public Specification / Contract materials for
**UNFYND Core** (on-device memory and intelligence infrastructure), plus
synthetic illustrative examples. Licensed under **Apache License 2.0**.

## What this repo is not

- The UNFYND App
- The private product monorepo
- Release Class B commercial / enterprise technology packages
- A claim that the full stack is open source

App implementation, proprietary tuning, AI Packs, corpora, and secrets stay in
private trees until a later explicit decision.

## License and trademarks

- Code and documentation in this pack: Apache-2.0 (`LICENSE`).
- **UNFYND®** and **UNFYND Core®** are product marks; see `NOTICE`. Apache-2.0
  does not grant trademark rights beyond reasonable attribution.

## Honesty bar

Public materials must keep App vs Core clear, and must not claim unfinished
Converse, Act/agents, Links/Event/Knowledge as shipped, or marketing AVAILABLE
semantic-recall SLAs without a measured product decision.

## Changes

Maintainers accept documentation PRs that stay within Class A. Broader openness
(App source, Class B, Model decisions) requires a separate product ADR outside
this pack’s default authority.
