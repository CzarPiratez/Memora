# Contributing

Thanks for interest in the **UNFYND Core** Class A contracts pack.

## What this repository is

Docs, contracts, and **synthetic** illustrative examples under Apache-2.0.
It is **not** the UNFYND App source tree.

## In scope

- Clarifying public contracts (`SPEC.md`, status, roadmap, security notes)
- Fixing documentation accuracy (over-claims, missing non-claims)
- Improving synthetic examples without personal or private fixtures
- Small doc hygiene PRs

## Out of scope (do not open here)

- UNFYND App / private monorepo source
- Secrets, keystores, credentials, `local.properties`
- Personal evaluation fixtures or private corpora
- AI Pack weights or proprietary pack configs
- Requests to open the App or Class B commercial packages (needs a separate
  product ADR elsewhere)

## How to file issues

Use: https://github.com/CzarPiratez/unfynd-core/issues

- Do **not** paste secrets, personal data, or private App paths into issues or PRs.
- Prefer enough detail to locate a docs problem without attaching user content.
- App-specific bugs belong with the App maintainers, not this pack tracker
  (unless the publisher expands scope later).

## Pull requests

Contributions to **this docs pack** are welcome via pull request to this
repository. By opening a PR, you agree your contribution is offered under the
same Apache License 2.0 as the pack. There is no separate CLA process for these
documentation contributions.

Maintainers may edit for honesty (App vs Core, non-claims) and Class A scope.
