# Contributor Covenant Code of Conduct

## Our pledge

We as members, contributors, and maintainers pledge to make participation in
this Class A contracts pack a harassment-free experience for everyone.

## Our standards

- Be respectful and precise. This pack is contracts and synthetic examples.
- Do not paste secrets, personal data, private App paths, or evaluation
  corpora into issues or pull requests.
- Assume good faith; correct over-claims rather than inflating them.

## Enforcement

Report unacceptable behavior via the website contact at
[https://www.unfynd.com/](https://www.unfynd.com/) or the copyright contact
in `NOTICE`. Do not file secrets in public issues.

Maintainers may edit or reject contributions that leave Class A scope, imply
the App is open, or weaken evidence honesty.
